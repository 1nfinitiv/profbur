# Mobile Well Drilling

1. Тип сайта
Одностраничный лендинг с якорным меню. Без форм обратной связи. Вся связь — по телефону.
2. Структура и блоки
Шапка (header):
Логотип (слева)
Меню: Услуги | Преимущества | Галерея | Контакты
Кнопка справа: «Позвонить нам» (ведёт на номер телефона, кликабельная)
Первый экран (главный):
Заголовок: «Бурение скважин там, где другие не проедут»
Подзаголовок: «Мобильные гусеничные установки — работаем на любом участке без подъезда»
Кнопка: «Позвонить мастеру» (ссылка на номер)
Преимущества:
Вместо списка «без воды» — сделай акцент на мобильности:
Заезжаем туда, куда не въезжают другие
Не портим газоны и дорожки
Работаем без подъезда
Поднимаемся на склоны и холмы
Быстро, чисто, без грязи
Услуги:
Бурение под ключ
Бурение без обустройства
Ремонт скважин
Чистка скважин
Зимняя консервация
Галерея:
Фото техники (в работе, на участке, в сложных условиях)
Фото процесса
Фото готовых скважин
Цены (информационно):
Стоимость за метр (в зависимости от грунта)
Доп. услуги (обсадка, насос, кессон)
Точную стоимость рассчитываем после выезда
Контакты:
Телефон (выделен крупно)
MAX (иконка с номером, без форм)
Карта с зоной обслуживания
3. Важные нюансы
Без форм заявок, без «оставьте заявку», без «рассчитать стоимость».
Вся связь — через звонок и мессенджеры.
Кнопка «Позвонить нам» — в шапке и в каждом важном блоке.
Телефон должен быть виден на всех экранах (стационарно или в меню).
Контакты вынесены крупно и привлекают внимание.
4. Техническое задание для разработчика
Адаптив под все устройства (телефон, планшет, десктоп)
Все кнопки — кликабельные номера телефонов
Карта с отметкой зоны обслуживания
Сбор статистики (счётчики Яндекс.Метрики и Google Analytics) — чтобы видеть, сколько звонят
Фото галерея без тяжелых скриптов

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
